# VaultPanel — stan projektu

Repozytorium jest na etapie zbierania źródeł. Nie zawiera jeszcze działającego panelu, backendu ani instalatora NAS. Moduły wymienione w dokumentacji są zakresem do zweryfikowania, a nie gotowymi funkcjami.

- [Audyt i lista braków](AUDIT.md)
- [Architektura i wymagane źródła](ARCHITECTURE.md)
- [Bezpieczny eksport z urządzenia](SOURCE_EXPORT.md)
- [Warunki przygotowania instalacji](INSTALLATION.md)
- [Licencje](LICENSING.md)

Nie przesyłaj całych katalogów systemowych, danych NAS, baz, logów, haseł, tokenów ani kluczy. Eksportuj wyłącznie ręcznie wybrane pliki źródłowe do prywatnego katalogu roboczego. Sprawdź je lokalnie przed udostępnieniem. Narzędzie skanujące pomaga znaleźć podejrzane wartości, ale nie gwarantuje anonimowości ani braku sekretów.
