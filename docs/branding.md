# VaultPanel branding

The approved lockup is the latest owner-supplied image, containing the vault symbol and geometric VaultPanel lettering. `frontend/assets/brand/vaultpanel.png` is a byte-for-byte copy of that approved image. It supersedes the earlier wordmark-only screenshot. No AI-generated reconstruction is used.

The same lockup is used on light and dark surfaces, retaining its dark background, exact geometry, spacing and natural aspect ratio. Do not stretch, recolor or apply CSS filters. No seam edits were applied to this replacement image.

The favicon and Apple touch icon use the vault symbol cropped from the approved image with its original dark background. The ICO contains 16, 32 and 48 pixel PNG frames.

README, the demo dashboard and the project presentation reference these assets. GitHub Pages stages only the four explicitly named brand files, alongside the existing HTML, CSS and JavaScript. Other screenshots, private configuration and payment material are excluded.
