# VaultPanel v0.2.0-alpha

Experimental, local, read-only prerelease. MIT licensed. No NAS installation or live hardware validation was performed for this release.

## Changes since v0.1.0-alpha

- Retro is the sole dashboard. The application `/` and `/retro` routes show the same interface; former Classic demo links forward to Retro.
- Optional mdraid membership reads are disabled by default and kept separate from BTRFS scrub results. Missing evidence stays unknown. No repair or device commands are introduced.
- The static Retro demo includes seven clearly labelled service examples and descriptions. These are fictional readings, not installed integrations.
- Repository branding is restored.
- Source packaging requires an explicit prerelease version, rejects unsafe inputs and existing output, preserves Git file modes, and verifies every source entry and checksum. Documentation changes no longer automatically publish releases.

## Use and limitations

Evaluate in a fresh directory on a separate development machine or disposable VM, following `docs/INSTALLATION.md`. Do not overwrite an existing NAS deployment. Keep default configuration for the first evaluation. The app is loopback-only; proxy/remote deployment is unsupported. Local readings belong to the evaluation machine, not a remote NAS.

Fan, LED, OLED and backup operations remain disabled. Real sensor accuracy, mount-to-array mapping, backup restoration and manual screen-reader use are unverified. This release does not claim production readiness or certified hardware support. UPS work remains excluded.
