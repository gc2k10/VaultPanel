# v0.2.0-alpha — candidate notes (unreleased)

This is the working identifier for the next experimental, local, read-only release. It is not a tag or published release. v0.1.0-alpha remains immutable.

## Changes since v0.1.0-alpha

- Retro is the only dashboard. `/` and `/retro` serve the same interface; the Classic template, styles and script are removed. Old demo links forward to Retro.
- Optional mdraid membership reads are disabled by default. Membership, maintenance and missing evidence are distinguished from BTRFS scrub results; no repair or device commands are added.
- The public static demo uses the real Retro template and fictional data. It includes seven explained service examples. These are not installed integrations.
- The approved repository logo is restored.
- Source packaging requires an explicit prerelease version, refuses existing output and dirty tracked files, excludes untracked data, preserves executable modes and verifies content/checksums against Git objects.
- CI stores a source candidate after application checks. An artifact is not a release. Documentation changes no longer trigger automatic publication.

## Compatibility and evaluation

Python 3.10+; CI includes Linux x64 and ARM64/Python 3.13.5. This does not certify the owner's Debian/kernel/controller combination. Existing read API routes remain available, and `/api/storage` adds mdraid evidence. `VAULTPANEL_MDRAID_READS=false` is the default. There are no database or NAS migrations.

Evaluate in a fresh directory on a separate development machine or disposable VM using INSTALLATION.md. Do not overwrite an existing deployment or copy private configuration into the repository. Start with no environment overrides. Any readings from a local evaluation belong to that machine, not a remote NAS. Stop the process to end evaluation; no service or startup task is installed.

## Unchanged limitations

Fan, LED, OLED and backup endpoints always deny writes. No hardware or backup operation is enabled. The dashboard is loopback-only; remote/proxy exposure is not supported. Physical sensor accuracy, actual mount-to-array mapping, restored backups and manual assistive-technology testing remain unverified. UPS work stays excluded. No live NAS access is required for preparation.

## Before publication

Record the exact final commit and passing application/demo checks, inspect the source candidate and checksums, and explicitly choose to publish this version. Do not rename an older ZIP or move an existing tag. Only create a new prerelease for the selected final commit after these gates. No production-readiness claim follows from automated tests.
