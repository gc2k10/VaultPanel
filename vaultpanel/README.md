# Recovered application source

This directory contains source recovered from the owner-operated installation and modified for an authenticated, loopback-only, read-only preview. See [installation](../docs/INSTALLATION.md), [source audit](../docs/SOURCE_AUDIT.md) and [license inventory](../docs/LICENSING.md).

Both `/` (classic) and `/retro` are available. Privileged web actions and the backup script are disabled. Hardware scripts are preserved for review, gated and not installed or tested on hardware. Do not replace an existing working installation with this intake build.
